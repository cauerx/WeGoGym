# 🏋️‍♂️ WeGoGym — Personal Workout Tracker (iOS PWA)

Aplicativo moderno de treino pessoal projetado especialmente como **Web App Progressivo (PWA)** para iPhone (iOS) e dispositivos móveis, com funcionamento 100% offline.

---

## ⚡ Funcionalidades

- **Treinos Estruturados**:
  - **Upper 1**: Paralela, Pullover (1 aquec + 2 trab), Remada baixa unilateral máquina, Tríceps francês máquina, Bíceps rosca W, Antebraço polia alta.
  - **Lower**: Cadeira Extensora (1 aquec + 2 trab), Cadeira flexora (1 aquec + 2 trab), Leg press 45, Elevação pélvica, Cadeira Adutora, Panturrilha.
  - **Upper 2**: Barra, Supino máquina (1 aquec + 2 trab), Crucifixo cross, Elevação lateral, Tríceps corda, Bíceps unilateral polia baixa.
- **Seletor de Unidade Individual (KG / LBS)**: Alterne individualmente cada exercício entre kg e lbs (com conversão automática para o cálculo de tonelagem global).
- **Classificação de Séries**: Badges táteis para alternar entre **Série de Trabalho** e **Série de Aquecimento**.
- **Tonelagem em Tempo Real por Grupamento Muscular**: Gráfico analítico de distribuição de volume por músculo (Peitoral, Costas, Tríceps, Bíceps, Quadríceps, Glúteos, etc.).
- **Cronômetro de Descanso (Rest Timer)**: Barra flutuante com tempo configurável, botões de ±15s, alarme sonoro sintetizado compatível com o Safari do iOS e início automático ao concluir séries.
- **100% Offline (PWA)**: Cache via Service Worker e persistência local via `localStorage`.

## 🚀 Como hospedar no GitHub Pages

1. Crie um repositório no GitHub (ex: `WeGoGym`).
2. Faça o upload de todos os arquivos desta pasta.
3. No repositório no GitHub, vá em **Settings** > **Pages** (no menu lateral esquerdo).
4. Em **Build and deployment** > **Source**, selecione **Deploy from a branch**.
5. Em **Branch**, escolha `main` (ou `master`) e a pasta `/(root)`.
6. Clique em **Save**.
7. Em cerca de 1 a 2 minutos, o GitHub gerará o seu link HTTPS:  
   `https://<seu-usuario>.github.io/WeGoGym/`

---

## 📱 Como instalar no iPhone (Safari)

1. Acesse o link do GitHub Pages no navegador **Safari** do iPhone.
2. Toque no botão de **Compartilhar** (ícone do quadrado com a seta para cima ⎋ na barra inferior).
3. Role para baixo e selecione **"Adicionar à Tela de Início"** (➕).
4. Toque em **"Adicionar"** no canto superior direito.
5. O aplicativo abrirá em tela cheia como um app nativo, sem barras de navegador!
